# A2A与Agent边界：共享任务能力，不共享整个人物库

本文不绑定特定A2A协议版本。协议适配器可以变，记忆域的用途、来源、最小披露、当前性和预算合同仍应成立。

## 1. 分清三个方向

| 方向 | 可以共享的条件 | 不能自动推导 |
|---|---|---|
| 同账号多入口 | 本人域中、入口已接入、用途/接收方适用 | 任何工具都能读完整账号 |
| 同账号子Agent | 父任务的有限能力和预算委派 | 子Agent永久可信或可自授确认 |
| 跨账号/外部Agent | 双方分别授权各自必要披露，真实对端合同成立 | 一方保存另一人的描述即获得对方许可 |

用户笔记里出现的第三人，仅是本域的被描述对象或本地别名。不能因为名称相同就把它连接成平台全域心理档案。

## 2. 受限投影的内容

```text
ExternalProjectionRef
  projection_id / payload_revision
  issuer / audience / task_ref
  purpose / allowed_field_refs / source_versions
  consent_version / deletion_epoch
  expires_at / payload_content_ref
  parent_budget_ref / allowed_effects
```

这是受信宿主与协议适配器的元数据草图，不是可以直接复制使用的能力令牌。实际签发、认证、重放防护和撤回方式需独立实现；模型文本中的同名字段不构成授权。

对外只包含完成任务所需的最少字段，例如明确选择的活动时间或沟通偏好。原始私聊、隐含动机、脆弱点、量表结果和心理画像首版不开放。任务投影不可直接透传完整ContinuationPackage。

## 3. 一个受限协作例子

完全虚构：用户希望个人Agent和另一个活动安排Agent核对可选时间。

1. 本人选择可披露的时间窗口与对端，明确仅用于当前协调任务。
2. 宿主准备最小投影，不附历史倾诉或关系判断。
3. 发送前核当前来源、目的、audience、期限与预算；接收方需验证真实issuer和任务亲本。
4. 对端返回可选项与其可观察来源，不把“建议可行”写成用户已接受。
5. 子Agent结果形成待核提案；用户选定或真实工具执行才有后续对应回执。
6. 撤回后停止新交付和结果提交；已发远程内容跟踪清理声明与未知范围。

这一任务不需要两家Agent交换完整人格模型，也不需要为平台所有账号两两启动对话。

## 4. 消息/任务/产物/记忆/行动分别完成

| 回执 | 可以证明 | 不能证明 |
|---|---|---|
| transport accepted | 传输端接受请求 | 对端模型理解或同意 |
| task completed | 对端按其合同完成任务 | 结果已被本人采纳 |
| artifact returned | 某版本产物到达 | 来源真实、许可仍有效 |
| memory committed | 本域记忆事务提交 | 外部行动执行 |
| tool receipt | 某可观察动作的受信证明 | 对方主观理解、关系改善或现实最终结果 |

恢复不能拿“上次模型看过”跳过当前权限，也不能因任务重入重放外部副作用。记忆交付、模型派发和Action.operation有各自幂等域。

## 5. 父子预算

子任务总输入/输出、工具次数、费用、并发和截止继承父预算上界；子Agent不能通过再委派绕过。预算预留到真实用量/未知状态对账，超时费用不当0元释放后重发。

控制操作有独立保留资源；模型额度耗尽不能剥夺用户停止/删除权。无活动账号不常驻Agent，匹配先做合法有界候选筛选，不全网两两调用模型。

## 6. 撤回与远程未知

| 位置 | 本域动作 | 对外承诺 |
|---|---|---|
| 尚未交付 | 阻断准入、清理本地受管正文 | 未交付范围可由真实回执说明 |
| 已交付但任务未提交 | 发停止/取消请求，拒本域迟到结果 | 不保证对端已擦除字节 |
| 对端确认收到清理请求 | 记录声明/receipt和范围 | acknowledgement不自动等于物理删除证明 |
| 对端无法核验/不支持限制 | 不开放该私人任务或保持未知 | 不用乐观UI掩盖缺口 |

内部缓存、投影、导出和接续包也要纳入依赖。能力过期不能作为延长正文保留的理由。

## 7. 专项验收

至少覆盖错误issuer/audience、越用途/字段、过期/撤回、旧版本重放、断线重连、ACK丢失、部分产物、子任务超父预算、对端伪造工具成功与远程清理未知。

同一团队两次调用不构成两家独立实现互操作证明；协议连接成功也不等于记忆用途和现实任务验收。对端无法提供必要身份、限制和期限合同时，私人共享保持关闭。
