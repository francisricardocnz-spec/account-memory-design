# 阶段与验收

本文件列实施验收规范，所有案例初始为planned，未执行。工具只检查文档包，不能把它的通过数写成以下产品案例通过数。

## 开发顺序

| 阶段 | 交付 | 出口要求 |
|---|---|---|
| R0 合同 | 字段、Schema、API、用途/保留、设置矩阵、幂等、停止ACK、成本配置 | 无未定义实现分支；缺配明确关闭；机器合同可审 |
| R1 最小完整闭环 | 新记录在至少两个声明入口保存/接续/纠正/停止/恢复；本人管理 | 核心工程与故障试验通过，读后可见，能真实退出 |
| R2 入口/迁移 | 全声明入口、合法旧记录显式升级、导出和全部受管副本 | 逐入口举证，不用聊天通过代替报告或工具 |
| R3 效果 | 独立故事、真实模型、合适授权的用户试点与消融 | 质量/安全/负担/费用分别合格，无增益层保持关闭 |
| R4 规模 | 目标分布/拓扑、N-1、限流、恢复和账单 | 实测吞吐、尾延迟、故障域与全成本；注册用户数不作容量证明 |

预算、有界查询和控制正确性从R0/R1开始。阶段不规定团队人数或承诺日程。

## 产品与工程案例

| ID | 操作/故障 | 必须观察的结果 |
|---|---|---|
| T01 | 保存一次后换入口 | 仅在已授权和已接入范围接续，来源可解释 |
| T02 | 没有记忆或拒绝建档 | 当前任务仍可帮助，不强制补人物字段 |
| T03 | 单次情绪/自嘲 | 不固化人格，不把引用或模拟当现实事件 |
| T04 | 一次明确偏好/边界 | 可按reported处理，当前边界不以持久保存为前提 |
| T05 | 内容confirmed但无长期Grant | 仍不能长期使用，准确显示缺门 |
| T06 | confirmed但推断仅provisional | 不提高支持，不长期激活 |
| T07 | 模型伪造owner/verified/actor/tool receipt | 拒相关提案，不因Schema合法赋权 |
| T08 | 同事件反复讲述/摘要再摘要 | 支持独立组不增加，新增细节保版本 |
| T09 | 新反例、不同情境或双方视角 | 不按最新日期强制覆盖，保冲突与适用范围 |
| T10 | 明确否定+替代保存各边界失败 | 停止保持，替代不谎称成功；纯替代事务全交全回滚 |
| T11 | 两实例同时纠正/生成 | CAS冲突明确，旧版本结果不提交 |
| T12 | 通知丢失时停止 | 正确性依权威屏障，不能靠WebSocket必达 |
| T13 | 删除后重放旧key/旧worker | 不复活、不重复扣费，回读不返已删正文 |
| T14 | 停止意图/DB应用/ACK之间崩溃 | 成功ACK有独立持久覆盖，可恢复原操作 |
| T15 | 恢复删除前旧备份/索引 | 先重放停止登记，缺失时历史能力关闭 |
| T16 | 临时状态/复核/保留/Grant分别到期 | 四种时间作用分开，不复活更旧画像 |
| T17 | 独立片段后删聊天或整来源谱系 | 保留/清理按披露范围，副本不能逃删 |
| T18 | 读关/撤权/额度耗尽后本人管理 | 合法停止/删除仍可用，正文另核权 |
| T19 | 换账号时旧请求返回 | 页面、选择、缓存、流式与本地副本不串账号 |
| T20 | 第51条后的旧事/200候选外关键反例 | 有界按范围找，超限报告不足，不宣称不存在 |
| T21 | 新确认未索引、索引乱序有洞 | 权威增量可读，连续水位不跨洞 |
| T22 | 翻页期间改权限/内容 | cursor重核/失效重开，ID版本去重 |
| T23 | 预览后新增工具/媒体/模型版本 | 最终同装配重计量，严格预算无法证明则拒派发 |
| T24 | ACK丢失、部分输出、迟到回执 | 不盲重发、不推进未有效交付游标，未知费用保留 |
| T25 | 旧SDK/供应商历史含失效正文 | 移除或干净generation重建，不追加忽略继续发 |
| T26 | 高扇出删除、闭包暂停/超界 | 根/域先阻断，相关投影不可借worker延迟继续读 |
| T27 | 无候选许可进入重试/异常日志 | 不持久存正文、前缀或可重建摘要；TTL不续 |
| T28 | 角色自述/工作方法/用户记忆混入 | 命名空间和权威分开，不增用户独立证据 |
| T29 | 草稿/计划/自报完成/工具发送 | Action阶段、证明与完成对象正确，结果未知保留 |
| T30 | A2A越字段/用途/期限/亲本预算 | 拒绝；对方回执不伪称远程物理删除 |
| T31 | 大账号、冷缓存、N-1、供应商限流 | 有界、公平、控制优先、费用和尾延迟如实报告 |
| T32 | 导出/撤销/缓存/旧回执/恢复含已删正文 | 纳入删除面，下载交付重核，不靠undo保隐藏全文 |

## 五类证据

分别保留结构合同、并发/恢复工程、真实模型语义、独立人工评审和真实用户任务收益。合成数据有助于覆盖边界，不替代真实人群结论。一次运行可关联多个案例，不能拆成多个独立用户样本。

先比较无长期记忆、事实记忆、人物/关系视图与可选高级层，固定任务、来源、模型、最终预算并报告总调用、尾延迟和置信区间。生产私人数据不自动转为评测/训练用途。严重越权和停止后复活发现一例即阻断，平均高分不抵消。
