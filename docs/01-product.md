# 产品需求

## 目标与范围

同一账号在已声明接入的对话、报告和工具中，按任务需要使用合法、当前有效、可解释的记忆。用户无需反复说明背景，也无需维护完整人物表格。来源不足保持未知，用户可以检查、纠正、缩小范围、停止或删除。

首版优先成年人自愿提供的自述、事件、当前状态、目标、明确偏好和有边界的局部假设。心理诊断、全局人格等级、自动因果确证、生产私聊训练与心理画像A2A共享不在默认范围。

## 用户路径

| 功能 | 用户看到什么 | 必须成立的结果 |
|---|---|---|
| 启用与设置 | 已支持入口、读取/新候选/有限整理的区别 | 未开启仍能使用本次输入；未接入口如实说明 |
| 保存 | 最多3张候选卡；原话、性质、用途、范围和保留说明 | 确认内容和允许使用分别记账；真实提交后才提示已保存 |
| 接续 | 任务相关背景，必要时可查看依据 | 不相关历史不常驻；没有合法记忆不补造画像 |
| 检查 | 记忆中心、来源详情、人物/议题筛选与分页 | 区分原话、整理、推断、时间和当前状态 |
| 纠正 | 不准确、已变化、补充、不再使用等反馈 | 明确否定先停止旧解释；新说明的保存另有回执 |
| 停止/删除 | 已阻断、清理中、完成范围、外部未知 | 不要求先证明模型错误或重新开启AI读取权限 |
| 历史升级 | 哪些旧条目具备来源与许可，哪些不符合 | 会话级旧记录不能自动成为账号共享记录 |
| 主动复盘 | 用户选定时间和议题 | 不为闲置账号每天启动模型；无回访不推断失败 |

## 信息性质

自述不等于独立核验；一次情绪不等于稳定人格；计划不等于执行；工具发送成功不等于对方已读或同意。用户一次明确偏好可以构成自述，不机械要求多次重复；推断长期使用需更严格的支持、确认、用途与来源门。

`insufficient`只用于澄清和表达未知；`provisional`只作明确局部的本轮假设或合法候选。`supported/corroborated`也不会自动获得长期、敏感或对外使用许可。

## 三设置与总内容写门

| 组合 | 实际能力 |
|---|---|
| 共享读取开、候选关 | 旧合法记忆可接续，不自动生成新候选；本人主动保存仍走完整门控 |
| 共享读取关、候选开 | 仅从当前输入产生候选，不后台补读旧正文；候选落盘仍需独立许可 |
| 整理开、共享读取关 | 保留设置值，暂停依赖历史的整理并说明原因 |
| 全部新内容写入禁用 | 停新保存/候选落盘/整理内容写，必要停止和清理控制继续 |

有限整理白名单初始为空。生成候选不等于允许持久保存候选，关闭读取不等于删除数据。本人管理应与AI使用准入分开，正文展示/导出另核保留和敏感限制。

## 成功标准

分别衡量跨入口接续、错误纳入、关键事实/反例召回、纠正后的实际回答、用户控制完成率、重复说明负担、尾部时延与每成功任务总成本。记忆条数、披露量、聊天时长和对AI的依赖不是正向目标。

任何已知跨账号泄露、停止后复活、未确认推断长期使用都应阻断发布，不能用平均分抵消。工程通过、真实模型语义效果、人工评审和真实用户收益分别举证。
